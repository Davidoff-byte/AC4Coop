# AC4 Co-op test kit - 2026-11-25

Branch `feat/integration-1121`. Game: AC4BFSP.exe PC 1.05 only (sha256 `bc11ad79...ab5150`; any other build is refused
and runs unmodded). Kit name, commit and ASI sha256 are in the package's `README.txt`. Everything below says what was
**verified** (and how) and what was **not**.

## 1. What is in the kit
| File | What |
|---|---|
| `AC4CoopLauncher.exe` | installs the mod into the game folder and starts the game armed for co-op |
| `files\AC4Coop.asi` | the mod, built from the commit in the kit name |
| `files\AC4Coop.ini` | the shipped template **plus the test overrides** of section 4 |
| `files\dinput8.dll` | Ultimate ASI Loader |
| `files\eos\`, `files\coop_ui\` | the EOS bridge for the lobby code, the F10 panel |
| `GUIDE.md` | this file |

## 2. Install (both players)
1. Close the game. In the game folder, **rename an existing `AC4Coop.ini`** (e.g. to `AC4Coop.ini.mine`): the launcher
   copies the kit's ini only when there is none, and the overrides below only reach you through that copy.
2. Unzip the kit anywhere, keep `files\` next to `AC4CoopLauncher.exe`, run the launcher, press **PLAY CO-OP**.
   The launcher backs up files it replaces (`*.launcher-bak`) and writes its own co-op keys on top of the ini
   (EOS transport, role from the panel, `BindRadiusM=60`, ...).
3. In the game press **F10**: one player clicks Host and sends the 6-letter code; the other types it and clicks Join.
4. Back up your saves first: the real save is `<game>\save3dmgames` (not the Ubisoft launcher folder).

Not verified on this branch: the launcher + EOS lobby path. Every result in section 3 comes from **two copies on one
PC** started directly from the exe (`tools\two_copy.ps1`, Mode=host/join on loopback). A two-machine run is the first
thing this kit should tell us.

## 4. The test overrides (in `files\AC4Coop.ini`, from `tools\kit\test-2026-11-25.overrides`)
| Key | Value | Why |
|---|---|---|
| `IntentLane` | 1 | the reliable lane every decision feature rides on; the shipped template had 0, which silently disabled the Brain set, OwnerDamage and SpawnKeyBind |
| `DisableSpawns` | 0 | keep the games' own NPCs and ships; the sync binds them (with 1 both worlds are empty) |
| `FightIntents`, `GuardActionLane`, `AttackForward` | 1 | fight decisions and guard actions over the lane (the owner-session set) |
| `CoordSync` | 1 | host -> guest object fields (ship hull and similar) |
| `ShipSync`, `ShipGhost` | 1 | ship records and the partner's ship |
| `ShipMirror` | 0 | its ship copies make the **fast-travel guest crash** (5/5 with copies alive) |
| `ShipClassBind` | 2 | enemy ships bound by class and driven with physics; 1 = render only (does not reach AI ships), 0 = off |
| `SpawnKeyBind` | 1 | NPCs bound to the same spawn on both games; needs `IntentLane=1` and `DisableSpawns=0` |
To turn a feature off, set its key to 0 in the game folder's `AC4Coop.ini` and restart the game.
`ShipClassBind` is re-read every second, so it can be changed while playing.

## 5. Known problems (do not report these as new)
- Guest AI ships still run their own AI and cannons: a bound enemy ship can fire on the guest that the host's never did.
- AI-ship crews are not synced; boarding is not synced; forts are not synced.
- Fast travel from the sea into Havana with ship copies alive crashes the guest (that is why ShipMirror is 0 here).
- After a fast travel the guest repopulates on its own (spawns during loading are not held). Key binding after a travel
  was **not tested** (only at boot); if guests stand in the wrong places after a travel, say so.
- The guest's own ships with no host counterpart are left alone (they can appear only on the guest screen).

## 6. What to send back
From each player's game folder, after the session:
- `phase1_log_<pid>.txt` (one per game start), `net_log*.txt`, `AC4Coop_crashctx_*.txt` if any;
- crash dumps: `%LOCALAPPDATA%\CrashDumps\AC4BFSP.exe*.dmp` if any;
- a sentence per check in section 3: worked / did not / not reached, and what you saw.
The first log line `[Build] asi=` must match the sha256 in `README.txt`.

## 7. Rolling back
Restore `AC4Coop.ini.mine` (or `AC4Coop.ini.launcher.bak`) and the `*.launcher-bak` files, or start the game from Steam /
Ubisoft Connect: a plain start runs the game unmodded (`[Launcher] RequireArm=1`).
