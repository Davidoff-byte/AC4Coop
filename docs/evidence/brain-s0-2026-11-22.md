## Pre-registered (written before the run)
Rig: two copies on one PC, started from the exe (`tools/two_copy.ps1`), boot save (Dry Tortuga fort, friendly pirates),
no teleport. Flags on top of the rig ini: `PeerClock=1 PeerClockSkewMs=250 Brain=1 BrainTest=1`. 150 s idle.

1. **Clock.** On one PC both copies read the same QPC, and the host adds 250 ms, so the true guest offset is +250 000 us.
   Over every guest `[Clock]` line from 10 s after the first estimate: `|offUs - 250000|` **p95 < 5000 us** = PASS.
   Control: the host's own line must read about -250 000 us (the same quantity seen from the other side).
2. **Lane.** For each host `[Brain] issue` marker whose guard the guest has bound (a guest `exec` or a guest stale/noBody
   counter explains every other): the host's `exec role=host` and the guest's `exec role=guest` for the same id/execMs.
   Execution moment in host time = execMs + lateMs on each side. **PASS:** ≥ 99 % of such markers execute on both, and
   `|lateHost - lateGuest| <= 33 ms` for ≥ 99 % of them. FAIL otherwise; markers lost to unbound bodies are reported, not
   excused.
3. **Capture (count only).** Friendly pirates at the fort are not expected to fight. Any `cap` line is recorded; zero
   captures is not a failure of this run.
