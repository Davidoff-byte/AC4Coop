Rig: two direct-started copies on one PC (host top-right, guest bottom-left), Dry Tortuga save
`save3dm-20261125-102017-drytortuga`, session flags `ShipSync=1 ShipClassBind=2 ShipClassBindSteal=1 ShipSpawnReplay=1
SpawnKeyBind=1 SpawnLib=1 SpawnLibFollow=1 ShipGhost=0 ShipMirror=0 IntentLane=1 DisableSpawns=0`.
Commands: `[Coop] SpawnCmd=ship|npc[:keyhex]`, one spawn per change of `SpawnCmdSeq`, `SpawnCmdPid` = host pid.
Dumps triaged with `tools/dump_triage.py` + cdb x86; code read in IDA 9.3 (`AC4BFSP.exe` md5 2058342866688f780c8b34526a65bc35).
